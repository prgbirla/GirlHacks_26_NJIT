How the realm is built

Forests

One per field. Each has its own tree color, so you can tell them apart from above.

Trees

Big concepts like Vectors or Derivatives. These are the nodes you travel between.

Shrubs

Smaller ideas that belong to a tree, like vector addition or the dot product.

Paths

Directed links between trees. Walk them backward for prerequisites, forward for what's next. A tree can have many of each.
